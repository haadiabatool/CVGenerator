# CV Generator<br>

A simple and user-friendly CV Generator built with HTML, CSS, and JavaScript.
This project allows users to enter their personal and professional information and instantly generate a formatted CV.<br>

## 📌 Project Overview<br>

The CV Generator provides a form where users can enter information such as:<br>

→ Name<br>
→ About Me<br>
→ Skills<br>
→ Education<br>
→ Work Experience<br>
→ Languages<br>
→ Hobbies<br>
→ Phone Number<br>
→ Email<br>
→ Address<br>
→ Profile Picture<br>

After submitting the form, the entered information is dynamically displayed in a professional CV template.<br>

##🛠️ Technologies Used<br>
→ HTML5 – Structure of the application<br>
→ CSS3 – Styling and CV layout<br>
→ JavaScript – Dynamic CV generation and image handling<br>
